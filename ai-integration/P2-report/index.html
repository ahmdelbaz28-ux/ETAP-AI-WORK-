    1. الملخص التنفيذي

    تم بنجاح إنجاز كافة متطلبات الحزمة P2 (Behavioral Safety, Reachability, and Unified Error) وفق أعلى معايير الأمان المنهجي والسلامة السلوكية دون كسر أي من المسارات القائمة ودون أي تجاوز لنطاق الملفات المسموح بها حصراً. تم توحيد سلوك المنفذ المزدوج (services/study_executor.py و services/study_service.py وشيم engine/engine.py) بحيث أصبحت كافة الدراسات الـ 20 المسجلة في STUDY_DISPATCH إما قابلة للتنفيذ المباشر الآمن، أو ترفع الاستثناء المعياري الموحد SpecializedExecutionUnavailableError برمز كودي موحد SPECIALIZED_EXECUTION_UNAVAILABLE.

    2. تفاصيل المهام المنجزة

    المهمة 2.1: تعريف الخطأ الموحد SpecializedExecutionUnavailableError

    • الملف: core/exceptions.py
    • تم إنشاء الفئة كـ subclass من ValueError لضمان التوافقية العكسية مع طبقات الاستدعاء: 
      class SpecializedExecutionUnavailableError(ValueError):
    """Raised when a study type is registered but no specialized execution handler is available."""

    def __init__(self, study_type: str, reason: str = ""):
        self.study_type = study_type
        self.code = "SPECIALIZED_EXECUTION_UNAVAILABLE"
        msg = f"Specialized execution unavailable for study '{study_type}'"
        if reason:
            msg += f": {reason}"
        super().__init__(msg)

    المهمة 2.2: ضبط مسارات التوجيه في services/study_executor.py

    1. معالجة الـ 11 نوع Agent غير المدعومة بالتشغيل الذاتي المباشر:
    2. في _dispatch_agent: عند عدم توفر بيئة متخصصة لدراسات الوكلاء الـ 11 (مثل harmonic_analysis، optimal_power_flow، motor_starting، transient_stability، cable_sizing، earth_grid، renewable_integration، battery_storage، scada، digital_twin، generative_design): يتم رفع SpecializedExecutionUnavailableError(study_type, "Agent execution requires specialized runtime").
    3. معالجة نوع المعالج external في _dispatch:
    4. استبدال ValueError برفع: SpecializedExecutionUnavailableError(canonical, f"handler_type '{registration.handler_type}' is external/not supported natively") للدراسات الخارجية مثل optimization.
    5. دراسة breaker_duty:
    6. التحقق من الـ Feature Flag الصارم is_strict_feature_enabled("breaker_duty"). عند التعطيل، رفع: SpecializedExecutionUnavailableError("breaker_duty", "Study type 'breaker_duty' is disabled by feature flag").
    7. دراسة ahmed_etap_orchestration:
    8. توجيهها الصريح إلى _dispatch_agent مع إحاطتها بـ try/except لرفع SpecializedExecutionUnavailableError عند تعذر تهيئة أو استدعاء الأوركستريتور: raise SpecializedExecutionUnavailableError(study_type, f"Orchestrator execution unavailable: {exc}") from exc.

    المهمة 2.3: مواءمة المنفذ الثاني وشيم المحرك

    1. في services/study_service.py (_run_native_study):
    2. استبدال الـ ValueError برفع: SpecializedExecutionUnavailableError(study_type, f"Unsupported native study type: {study_type}").
    3. في engine/engine.py (run_study):
    4. استيراد STUDY_DISPATCH وفحص المدخل: إذا كانت الدراسة ضمن الدراسات المسجلة في STUDY_DISPATCH ولكنها خارج الدراسات الأصلية الأربع للمحرك، يتم رفع: SpecializedExecutionUnavailableError(study_type, "not supported in native engine shim").
    5. أما إذا كان نوع الدراسة غير معروف إطلاقاً (مثل "bogus")، فيستمر في رفع ValueError(f"Unsupported study type: {study_type}") حفاظاً على دقة التعاقد القديم واختبارات الـ regex القائمة في tests/test_run_study_registry.py.

    المهمة 2.4: حزمة اختبارات بوابة الوصول والمطابقة الشاملة

    • الملف الجديد: tests/test_study_reachability_gate.py (21 اختباراً شاملاً):
    • TestStudyReachabilityGate:
      • فحص أن STUDY_DISPATCH يحتوي بالضبط على 20 دراسة مسجلة.
      • فحص كل مدخل من الـ 20 عبر المنفذين والتأكد من انعدام الـ ValueError المجهول: إما تنفيذ ناجح أو رفع SpecializedExecutionUnavailableError بكود SPECIALIZED_EXECUTION_UNAVAILABLE.
      • فحص خط الأنابيب الكامل execute(StudyRequest(...)) للأنواع المدعومة.
    • TestDualPortParity:
      • اختبار مطابقة الـ Parity لكافة الدراسات الـ 12 غير الأصلية عبر:
      • المنفذ 1: study_executor._dispatch
      • المنفذ 2: study_service._run_native_study
      • شيم المحرك: engine.run_study وإثبات أنها جميعاً ترفع SpecializedExecutionUnavailableError بنفس الكود الموحد.
    • TestNativeFourStudiesPreservation:
      • التحقق الشامل من سلامة المسارات الأصلية الأربعة (load_flow، short_circuit، arc_flash، protection_coordination) وعملها بنجاح تام 100% عبر كل الطبقات.
    • TestUnregisteredAndSpecialStudies:
      • إثبات رفع ValueError العام للدراسات الوهمية/غير المسجلة لتمييزها عن الدراسات المسجلة غير المتاحة تشغيلياً.
      • إثبات رفع SpecializedExecutionUnavailableError عند تعطيل علم breaker_duty.
