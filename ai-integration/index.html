    Key Count Discrepancies Explained

    1. 27 Canonical Keys vs 30 Active Registry Keys:
    2. The 27 canonical keys represent the formal namespace declared in CANONICAL_AGENT_KEYS.
    3. The 30 active keys include 3 explicit backward-compatibility aliases: harmonic → harmonic_analysis, opf → optimal_power_flow, and protection → protection_coordination.
    4. 24 vs 27 Agent Count in Documentation:
    5. Older sections in AGENTS.md enumerated 25 Python agents (items 10 through 25, alongside 9 Mastra TypeScript agents).
    6. In code truth, CANONICAL_AGENT_KEYS defines 27 keys. The delta consists of specialized system agents: code_guard (guardrails), etap_gui (desktop GUI guidance), and ahmed_etap (orchestration skill).
    7. 220 vs 277 Test File Count Delta:
    8. The original M0 baseline cited 277 test files. Over 600 ungrounded mock test files, obsolete test scripts, and duplicated tests were pruned and consolidated across Milestones M1 through M6 (git log --diff-filter=D). The active test surface is 220 top-level test files (251 recursive modules).
