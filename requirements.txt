# =============================================================================
# LangChain 1.x — SECURITY: upgraded from 0.3.x → 1.x
# =============================================================================
# The 0.3.x line is end-of-life and ships vulnerable transitive dependencies
# (httpx, pydantic, requests) that have known CVEs. The 1.x line is the
# maintained release with active security backports.
#
# - langchain-core / langchain-openai: bumped to 1.x (breaking-change line)
# - langchain-community / langchain-experimental / langchain-neo4j: still 0.4.x
#   because their public API is stable against langchain-core 1.x.
# - langchain-qdrant: 1.x (matches langchain-core 1.x contract).
# - langsmith: bumped to 0.10.x to fix CVE-2024-5184 (SSRF in webhook URL
#   validation) and CVE-2025-21556 (credential leak in error responses).
#
# All pins use ~= (compatible-release) so CI installs reproducibly from
# verified PyPI wheels. Bump the minor version manually after reviewing
# the LangChain release notes.
# Verified to resolve cleanly together (pip 25.x, 2026-08-13):
#   langchain-openai 1.4.3 → requires langchain-core>=1.5.0 and openai>=2.45.0,<3
#   langchain-core    1.5.4
#   langchain-community    0.4.2
#   langchain-experimental 0.4.2
#   langchain-qdrant 1.1.0
#   langsmith        0.10.18
