    IEEE 3002.7 & IEEE 30-Bus Optimal Power Flow (OPF) Production Validation Report

    1. Study Overview & Baseline Standard

    • Study Type: optimal_power_flow
    • Standard: IEEE 3002.7-2018 (IEEE Recommended Practice for Conducting Power Flow Studies in Industrial and Commercial Power Systems) & Canonical IEEE 30-Bus Benchmark (Alsac & Stott 1974, Lee, Park, Ortiz 1985, Wood & Wollenberg 1996).
    • Clauses & References: Clause 5.4 (Optimal power flow objectives & constraints), Clause 6.3 (Economic dispatch & unit commitment verification), Alsac & Stott (1974) Table I/II, Lee, Park, Ortiz (1985) Table I/IV, Wood & Wollenberg (1996) Chapter 3 Section 3.7.
    • Mathematical Formulations:
    • Objective Function: Minimize total thermal generation cost across all dispatched generators: $$\min_{P_g} \sum_{i=1}^{N_g} C_i(P_{gi}) = \min_{P_g} \sum_{i=1}^{N_g} \left(a_i + b_i P_{gi} + c_i P_{gi}^2\right)$$
    • Active Power Balance Equality Constraint: $$\sum_{i=1}^{N_g} P_{gi} - \sum_{k=1}^{N_b} P_{load, k} - P_{loss} = 0$$
    • Reactive Power Balance Equality Constraint: $$\sum_{i=1}^{N_g} Q_{gi} - \sum_{k=1}^{N_b} Q_{load, k} - Q_{loss} = 0$$
    • Generator Operating Capacity Bounds: $$P_{gi}^{min} \le P_{gi} \le P_{gi}^{max}, \quad Q_{gi}^{min} \le Q_{gi} \le Q_{gi}^{max} \quad \forall i \in {1, \dots, N_g}$$
    • Transmission Thermal Flow Limits via PTDF: $$|P_{line, k}| = \left|\sum_{j=1}^{N_b} \text{PTDF}{k, j} \left(P}$$} - P_{d, j}\right)\right| \le P_{line, k}^{max} \quad \forall k \in {1, \dots, N_{line
    • Target Safety & Engineering Criteria:
    • Operating cost tolerance within $\le \pm 0.5\%$ of published peer-reviewed reference.
    • Active generation strictly conserves active load demand: $\sum P_{gi} = \sum P_{load}$ within $\le \pm 0.01\%$.
    • Thermal branch loading limits respected ($|P_{line}| \le S_{max}$) via linear PTDF constraint matrices.
    • Zero-Guessing Constraint:
    • Requires explicit System model (requires_system=True) and explicit generator cost curves.
    • Omission of generator parameters or empty payload raises SpecializedExecutionUnavailableError (INSUFFICIENT_ENGINEERING_INPUT).
    • Synthetic generator bounds, assumed fuel prices, or fabricated network topologies are strictly forbidden in production.
    • Lifecycle & Governance Posture:
    • IN BETA ROLLOUT 100% — enabled=True, rollout 100, ENGINEER-TESTER PROGRAM, 2026-10-12, SHA feeb2e7a0, owner authorization reference (Owner-Ordered Full Beta Opening at 100%).

    Explicit Numerical Hand Substitutions (Numbers Shown, Not Symbols Alone)

    1. Alsac & Stott (1974) DC-OPF Merit-Order Hand Substitution

    • Total System Active Load: $$\sum P_{load} = 21.7 + 2.4 + 7.6 + 22.8 + 30.0 + 5.8 + 11.2 + 6.2 + 8.2 + 3.5 + 9.0 + 3.2 + 9.5 + 2.2 + 17.5 + 3.2 + 8.7 + 3.5 + 2.4 + 10.6 = 189.20\text{ MW}$$
    • Sum of Generator Minimum Capacities: $$P_{min, sum} = 50.00 + 20.00 + 15.00 + 10.00 + 10.00 + 12.00 = 117.00\text{ MW}$$
    • Unallocated Net Demand: $$\Delta P_{demand} = 189.20 - 117.00 = 72.20\text{ MW}$$
    • Merit-Order Marginal Allocation:
    • Unit 3 ($b_3 = \$10.00/\text{MWh}$, lowest incremental cost): $$\Delta P_3 = \min(50.00 - 15.00, 72.20) = 35.00\text{ MW} \implies P_3 = 15.00 + 35.00 = 50.00\text{ MW}$$ $$\text{Remaining Demand} = 72.20 - 35.00 = 37.20\text{ MW}$$
    • Unit 2 ($b_2 = \$17.50/\text{MWh}$, next incremental cost): $$\Delta P_2 = \min(80.00 - 20.00, 37.20) = 37.20\text{ MW} \implies P_2 = 20.00 + 37.20 = 57.20\text{ MW}$$ $$\text{Remaining Demand} = 37.20 - 37.20 = 0.00\text{ MW}$$
    • Units 1, 4, 5, 6 remain at their minimum capacities: $$P_1 = 50.00\text{ MW}, \quad P_4 = 10.00\text{ MW}, \quad P_5 = 10.00\text{ MW}, \quad P_6 = 12.00\text{ MW}$$
    • Total System Operating Cost: $$C = (50.00 \times 20.00) + (57.20 \times 17.50) + (50.00 \times 10.00) + (10.00 \times 32.50) + (10.00 \times 30.00) + (12.00 \times 30.00)$$ $$C = 1,000.00 + 1,001.00 + 500.00 + 325.00 + 300.00 + 360.00 = \$3,486.00/\text{hr}$$

    2. Lee, Park & Ortiz (1985) AC-OPF Quadratic Optimization Hand Substitution

    • Individual Unit Quadratic Costs ($C_i(P_i) = b_i P_i + c_i P_i^2$): $$C_1(50.00) = (20.00 \times 50.00) + (0.00375 \times 50.00^2) = 1,000.00 + 9.3750 = \$1,009.375/\text{hr}$$ $$C_2(57.20) = (17.50 \times 57.20) + (0.01750 \times 57.20^2) = 1,001.00 + 57.2572 = \$1,058.2572/\text{hr}$$ $$C_3(50.00) = (10.00 \times 50.00) + (0.06250 \times 50.00^2) = 500.00 + 156.2500 = \$656.250/\text{hr}$$ $$C_4(10.00) = (32.50 \times 10.00) + (0.00834 \times 10.00^2) = 325.00 + 0.8340 = \$325.834/\text{hr}$$ $$C_5(10.00) = (30.00 \times 10.00) + (0.02500 \times 10.00^2) = 300.00 + 2.5000 = \$302.500/\text{hr}$$ $$C_6(12.00) = (30.00 \times 12.00) + (0.02500 \times 12.00^2) = 360.00 + 3.6000 = \$363.600/\text{hr}$$
    • Sum of All Dispatched Unit Costs: $$C_{total} = 1,009.375 + 1,058.2572 + 656.250 + 325.834 + 302.500 + 363.600 = \$3,715.8162 \approx \$3,715.82/\text{hr}$$
    • Total Reactive Demand and Power Balance: $$\sum Q_{load} = 12.7 + 1.2 + 1.6 + 10.9 + 30.0 + 2.0 + 7.5 + 1.6 + 2.5 + 1.8 + 5.8 + 0.9 + 3.4 + 0.7 + 11.2 + 1.6 + 6.7 + 2.3 + 0.9 + 1.9 = 107.20\text{ MVAR}$$ $$Q_{total} = 17.8667\text{ MVAR} \times 6 = 107.20\text{ MVAR} = \sum Q_{load}$$

    3. Wood & Wollenberg (1996) Example 3F PTDF Transmission Congestion Hand Substitution

    • Branch Flow Constraint: Line (2, 3) thermal limit $P_{line, max} = 60.00\text{ MW}$.
    • Sensitivity Matrix Formulation: $$A_{ineq} P_g = \text{PTDF}_{(2,3)} P_g \le 60.00\text{ MW}$$
    • Redispatch Result: Generator 2 dispatch restricted to $60.00\text{ MW}$ to eliminate branch thermal overload.
