    S2 — إغلاق IEC 60909 (دوافع Method + توثيق البنود) — بند 1-5 المعلّق

    الصق هذا الملف وحده للوكيل المنفذ. توقف عند التقرير.

    هويتك وقوانينك

    R1 لا ادعاء بلا أمر + نتيجة حرفية. R2 تجميد أثناء القياس. R3 لا اختلاق (خاصة: لا تختر صيغة معيارية من معرفتك — إن لم يوجد مرجع داخل المستودع فاحذف الادعاء). R7 لا ملف خارج القائمة.

    حالة البداية المؤكدة

    • fault_analysis/iec60909_engine.py:148 → calculate_ku (التوثيق الحالي يذكر Clause 3.3.2 وClause 3.7).
    • _get_rx_ratio (424-435): يستخدم الجزء التخيلي بإشارته (مذكور بالسطر 432).
    • _calculate_kappa (437-449): Method A — kappa = 1.02 + 0.98*exp(-3*R/X) مع سقف 2.0؛ تُستدعى في 575، 691، 817، 935.
    • اختبار قائم: tests/test_iec60909_published_cases.py.

    الملفات المسموح لمسها حصريًا

    fault_analysis\iec60909_engine.py · tests\test_iec60909_published_cases.py (أو tests\test_iec60909_method_evidence.py جديد) · docs\status\STATUS_BOARD.md (إن وُجد ادعاء "Method B/C" في ملف توثيق آخر: أبلغني قبل لمسه — لا تلمسه في هذه المرحلة.)

    الخطوات

    1. مسح الادعاءات: git grep -n -i "method b" وgit grep -n -i "method c" على كل المستودع. اطبع كل نتيجة.
    2. حسمها بلا اختراع: لكل نتيجة إما (أ) يوجد كود فعلي مطابق → أرشفه بالمكان والسطر، أو (ب) لا يوجد → حذف الادعاء من مصدره إن كان داخل الملفات المصرَّح بها، وإلا فأبلغني.
    3. وثّق calculate_ku: اذكر البند المعياري الدقيق لعوامل KG/KT/KS مع تبرير التسمية، ولا تخلط بين Ku وعوامل التصحيح KG/KT. لا تغيير سلوكي.
    4. وثّق _calculate_kappa و_get_rx_ratio: مرجع البند، حدود الكبح [1.0, 2.0]، ومعنى R/X الموقّع.
    5. اختبارات أدلة (في الملف القائم أو الجديد):
    6. R/X = 0.1 → kappa محسوبة يدويًا (اكتب العملية الحسابية في تعليق) وتطابق دالة الكود.
    7. R/X → 0 → kappa = 2.0 (حد أعلى).
    8. R/X كبير (مثال 10) → kappa ≈ 1.02.
    9. إثبات أن حالات الاختبار المنشورة القائمة لم تتغير نتائجها (نفس المخرجات).
    10. حدّث STATUS_BOARD (صف S2) + التقرير بالنموذج.

    بوابة القبول

    • كل اختبارات محرك IEC 60909 خضراء بعد التعديل (سجّل الأعداد).
    • كل نتيجة git grep عن "method b/c" مغطاة: كود مطابق مُشار إليه، أو ادعاء محذوف.
    • توثيق البنود موجود حرفيًا في docstrings الملف.
    • ruff check fault_analysis/iec60909_engine.py نظيف.
