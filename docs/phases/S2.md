## الخطوات
1. **مسح الادعاءات:** `git grep -n -i "method b"` و`git grep -n -i "method c"` على كل المستودع. اطبع كل نتيجة.
2. **حسمها بلا اختراع:** لكل نتيجة إما (أ) يوجد كود فعلي مطابق → أرشفه بالمكان والسطر، أو (ب) لا يوجد → حذف الادعاء من مصدره **إن كان داخل الملفات المصرَّح بها**، وإلا فأبلغني.
3. **وثّق `calculate_ku`**: اذكر البند المعياري الدقيق لعوامل KG/KT/KS مع تبرير التسمية، ولا تخلط بين `Ku` وعوامل التصحيح KG/KT. لا تغيير سلوكي.
4. **وثّق `_calculate_kappa` و`_get_rx_ratio`**: مرجع البند، حدود الكبح `[1.0, 2.0]`، ومعنى R/X الموقّع.
5. **اختبارات أدلة** (في الملف القائم أو الجديد):
   - R/X = 0.1 → kappa محسوبة يدويًا (اكتب العملية الحسابية في تعليق) وتطابق دالة الكود.
   - R/X → 0 → kappa = 2.0 (حد أعلى).
   - R/X كبير (مثال 10) → kappa ≈ 1.02.
   - إثبات أن حالات الاختبار المنشورة القائمة لم تتغير نتائجها (نفس المخرجات).
6. **حدّث** STATUS_BOARD (صف S2) + التقرير بالنموذج.
