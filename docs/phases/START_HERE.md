# START HERE — كيف توجّه الوكيل المنفذ (دليل المالك)

## الدورة (تُكرَّر 9 مرات — مرة لكل مرحلة S0…S8)

```
أنت ───────────► تنسخ «رسالة التسليم» للمرحلة الحالية وترسلها للوكيل المنفذ
الوكيل المنفذ ──► ينفذ المرحلة ويكتب تقريره بنموذج docs/status/REPORT_TEMPLATE.md
أنت ───────────► تلصق تقريره كاملًا في محادثتي (المستشار)
المستشار ──────► يراجع الأدلة ويرد بـ: «تصريح ببدء المرحلة التالية» أو «تصحيح/إيقاف + السبب»
(ثم تعود للخطوة الأولى بالمرحلة التالية)
```

**قواعد سريعة:**
- **مرحلة واحدة فقط** في كل رسالة/جلسة — لا ترسل مرحلتين معًا (منعًا لفقدان سياق الوكيل).
- **لا تصرّح للمنفذ بالمرحلة التالية قبل ردّي.**
- إن شككت أن وكيلًا آخر يعمل على المستودع، أبلغني فورًا قبل أي شيء.
- قرارات المالك المعلّقة (D1–D6) في `docs/status/STATUS_BOARD.md` — مطلوبة تدريجيًا (D1 الآن، D2 عند S5، D4 عند S3، D6 عند S6).

## 📤 ماذا ترسل لي بعد كل مرحلة؟

انسخ تقرير الوكيل **كاملاً بدون تعديل** والصقه في محادثتي بهذا الشكل:

```text
تقرير المرحلة S0 من الوكيل المنفذ:
<الصق هنا تقرير الوكيل كاملًا: التعديلات + الأدلة الحرفية + نتائج البوابة>
```

## 📥 ماذا ستصلك مني؟

رد قصير من نوع واحد:
- **«تصريح S1»** + رسالة جاهزة تنسخها للوكيل، أو
- **«تصحيح»** + النقطة المحددة التي يجب إعادة تنفيذها (مثلًا: دليل ناقص أو رقم غير قابل للتكرار).
