# S6 — القياس النهائي الشامل (تجميد كامل)

> **الصق هذا الملف وحده للوكيل المنفذ. توقف عند التقرير.**

## القاعدة الحاكمة
**ممنوع تعديل أي ملف أثناء القياس.** أي فشل: أصلح الجذر وأعد القياس **من الصفر** (ممنوع الالتفاف، وممنوع `skip/xfail` لإخفاء فشل).
أثبت التجميد: `git rev-parse HEAD` قبل وبعد كل قياس = نفس القيمة، و`git status --porcelain` نظيف في النهاية (عدا ملفات التوثيق المعلنة).

## الخطوات (كلها بأدلة حرفية في التقرير)
1. **البوابة الكاملة:**
   ```powershell
   & .venv-fix/Scripts/python -m pytest tests/ --ignore=tests/load --ignore=tests/stress --ignore=tests/chaos -q --tb=short
   ```
   > **درس S0.1 (إلزامي):** xdist أنتج إخفاقات كاذبة (8 من 19 اختفت متسلسلًا بسبب تنافس SQLite بين العمال). لذلك:
   > - **التشغيل التسلسلي أعلاه هو المرجع الوحيد** لادعاء «0 failed».
   > - `-n 8` اختياري للسرعة فقط، وأي فشل يظهر متوازيًا **يُعاد فحصه تسلسليًا**:
   >   `& .venv-fix/Scripts/python -m pytest --lf -q -o addopts='' --tb=line`
   سجّل سطر النتيجة النهائي وسطر `finished in` **للتشغيل التسلسلي**.
2. **الجودة الساكنة:**
   ```powershell
   & .venv-fix/Scripts/python -m ruff check . --config ruff.toml
   & .venv-fix/Scripts/python validate_syntax.py
   & .venv-fix/Scripts/python validation_suite.py
   & .venv-fix/Scripts/python scripts/claims_audit.py --strict
   & .venv-fix/Scripts/python -m pytest tests/test_engineering_service.py -q
   ```
   > أرقام البرومبت (`validation_suite 31/31` و`test_engineering_service 74/74`) **ادعاءات تُقاس**: إن اختلفت سجّل الحقيقة وأبلغني فورًا.
3. **قياس التغطية (لا تغيّر العتبة):**
   ```powershell
   & .venv-fix/Scripts/python -m pytest tests/ -q --cov=. --cov-report=term-missing
   ```
   سجّل النسبة الحقيقية. أي `--cov-fail-under` يبقى معلّقًا حتى قراري (D6).
4. **الواجهة:**
   ```powershell
   pnpm -C ui typecheck ; pnpm -C ui test ; pnpm -C ui build
   ```
5. **دليل التجميد:** جدول (القياس | HEAD قبل | HEAD بعد | الشجرة) لكل بند.
6. **حدّث** STATUS_BOARD (صف S6) + التقرير بالنموذج.
